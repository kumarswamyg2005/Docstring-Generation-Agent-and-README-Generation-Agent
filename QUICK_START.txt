                    📖 DOCUMATE - Quick Instructions
              Automated Python Docstring Generator
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📦 WHAT IS THIS?
────────────────
DocuMate automatically adds professional docstrings to your 
Python code. No manual writing needed!


🚀 HOW TO USE (3 STEPS):
────────────────────────

STEP 1: Install dependencies (first time only)
  $ pip3 install -r requirements.txt

STEP 2: Navigate to your DocuMate folder
  $ cd /path/to/DocuMate

STEP 3: Run on YOUR Python code
  $ python3 main.py --docstrings --no-ai --directory <YOUR_CODE_FOLDER> --output <OUTPUT_FOLDER>


💡 REAL EXAMPLES:
─────────────────

Document a project:
  $ python3 main.py --docstrings --no-ai --directory ~/my_project --output ~/my_project_docs

Document specific folder:
  $ python3 main.py --docstrings --no-ai --directory ~/Desktop/python_code --output ~/Desktop/output

Use different style:
  $ python3 main.py --docstrings --no-ai --style numpy --directory ~/code --output ~/output


❓ COMMAND BREAKDOWN:
─────────────────────
python3 main.py          → Run the tool
--docstrings             → Generate docstrings
--no-ai                  → Fast mode (no internet needed)
--directory <path>       → Your Python code location
--output <path>          → Where to save documented code


📋 REQUIREMENTS:
────────────────
✓ Python 3.7 or higher
✓ That's it!


🎨 DOCSTRING STYLES:
────────────────────
--style google    → Google style (default)
--style numpy     → NumPy style
--style sphinx    → Sphinx style


🔍 EXAMPLE BEFORE/AFTER:
─────────────────────────

BEFORE (Your code):
  def add(a, b):
      return a + b

AFTER (DocuMate output):
  def add(a, b):
      """Add.

          Args:
              a (Any): Description of a.
              b (Any): Description of b.
          """
      return a + b


⚠️ IMPORTANT NOTES:
───────────────────
• Your original code is NOT modified (output goes to new folder)
• Works on entire folders or single files
• No internet needed with --no-ai flag
• Generates PEP-257 compliant docstrings


🆘 COMMON ISSUES:
─────────────────

"Python not found"
  → Install Python 3.7+ from python.org

"No module named xyz"
  → Run: pip3 install -r requirements.txt

"Permission denied"
  → Run: chmod +x main.py
